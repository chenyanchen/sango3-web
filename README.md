# 三国群英传 III · 重制版

宇峻奥汀《三国群英传3》（2002）的现代复刻：浏览器运行，**Windows / macOS / Linux / iPhone / iPad / Android 全平台可玩**。

**在线游玩：<https://chenyanchen.github.io/sango3-web/>**（首次打开时选择你自己的安装包，见下文）

- 原版全部数据（武将、城池、剧本、武将技、兵种、阵形、道具、事件）与美术、音乐直接取自你自己的游戏安装，**数值与原版一致**。
- 渲染：WebGL（PixiJS 8）+ 图集批量绘制，60 帧以上；高 DPI 清晰显示；宽屏显示更多战场而不是拉伸。
- 界面：可缩放的高清中文界面（原版为 640×480 位图字），鼠标 / 键盘 / 触屏均可操作。
- 繁体原版文本自动转换为简体。
- 存档在浏览器本地（10 个存档位 + 每月自动存档）。

## 在线游玩（推荐）

打开 <https://chenyanchen.github.io/sango3-web/>，按提示选择你自己的《三国群英传3》安装包（如 `三国群英传3合集.exe`），或游戏目录里的 `sango3.pak`（加上 `MUSIC.PAK` 才有背景音乐）。

- 网站**不包含任何原版素材**；解包和转换全部在你的浏览器里完成（Web Worker 多线程），文件不会上传。
- 首次导入约 1 分钟，素材约 300 MB 存在浏览器缓存里，之后秒开、可离线玩。
- 需要较新的 Chrome / Edge / Firefox / Safari，且不能是无痕模式。手机上没有安装包的话，可以先在电脑上解出 `sango3.pak` 和 `MUSIC.PAK` 传到手机再选。
- 「游戏设定 → 清除并重新导入」可以删除已导入的素材。

## 本地运行

需要 Node.js ≥ 22、pnpm；转码音乐需要 `ffmpeg`（没有则保留 WAV）。安装包解包为纯 TypeScript 实现，无需其他工具。

```bash
pnpm install
# 1) 从你的原版资源生成游戏素材（只需一次，约 30 秒）
#    参数可以是合集安装包 .exe，或已安装的游戏目录（含 sango3.pak / MUSIC.PAK）
pnpm extract ~/Downloads/sgqyc_35612/三国群英传3合集.exe
# 2) 开始游戏
pnpm dev            # 打开 http://localhost:5173
```

### 在手机 / 平板上玩

`pnpm dev` 会同时监听局域网地址（终端里显示的 `Network: http://192.168.x.x:5173`）。手机连同一个 Wi-Fi，用浏览器打开即可；横屏游玩，可“添加到主屏幕”以全屏运行。

### 打包发布（静态网站）

```bash
pnpm build          # 产物在 dist/（本地有 public/assets 时会一并打包，可放到任何静态服务器 / NAS）
pnpm preview --host
```

生产构建带 Service Worker，素材首次加载后离线缓存，之后秒开。如果服务器上没有 `assets/`，页面会进入上面的“选择安装包”导入流程。推送到 `main` 后，GitHub Actions 会自动构建并部署到 GitHub Pages（只含代码）。
