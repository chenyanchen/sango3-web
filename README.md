# 三国墨英传

一款水墨风格的三国策略游戏，玩法复刻自宇峻奥汀的《三国群英传3》（2002）。浏览器运行，**Windows / macOS / Linux / iPhone / iPad / Android 全平台可玩**。

**在线游玩：<https://chenyanchen.github.io/sango3-web/>**（打开即玩）

- **全部素材由代码生成**（`tools/gen`）：水墨画风的地图、头像、兵将动画、技能特效、战场与野战地形，合成的民乐配乐与音效，以及重新编写的武将、剧本、事件、道具、武将技数据。不含任何原版内容，体积约为原版素材的一半。
- **可选原版素材**：如果你有《三国群英传3》，可在「游戏设定 → 游戏素材」导入自己的安装包，切换为原版的画面、音乐与数据（在浏览器本地处理，不上传；两套素材的存档分开）。
- 渲染：WebGL（PixiJS 8）+ 图集批量绘制，60 帧以上；高 DPI 清晰显示；宽屏显示更多战场而不是拉伸。
- 界面：可缩放的高清中文界面，鼠标 / 键盘 / 触屏均可操作。
- 存档在浏览器本地（10 个存档位 + 每月自动存档）。

## 已实现

- **主选单**：新的游戏（6 个剧本、全部原版君主）、读取进度、自创武将、游戏设定、游戏说明。
- **内政大地图**：原版中国地图，拖动/缩放；内政、军政、外交、任免、计略、系统、休息全部指令；行动点数；AI 诸侯（开发、征兵、搜索、外交、离间、进攻）；历史事件；君主继承与势力灭亡；年末比武大会；每月自动存档。
- **野战**：从原版地图文件还原的 70 张城市战场；早晨/黄昏/夜晚、天气、地形移动消耗、城门耐久；攻击、单挑、阵形、待命、撤退、23 种军师计；委任与快进。
- **百人战**：原版精灵与动画、8 种阵形、9 兵种（含进阶兵种）相克、弓弩投射、骑乘武将、全部 125 种武将技、敌方 AI、雷达、1×/2×/3× 速度。
- **单挑**：攻击/重击/防御/必杀，完美格挡与反击。
- **结局**：统一天下（登基 + 制作人员名单）/ 势力灭亡。

## 原版素材（可选）

在「游戏设定 → 游戏素材 → 使用原版素材…」中选择你自己的《三国群英传3》安装包（如 `三国群英传3合集.exe`），或游戏目录里的 `sango3.pak`（加上 `MUSIC.PAK` 才有原版音乐）。

- 解包和转换全部在浏览器里完成（Web Worker 多线程），文件不会上传；首次导入约 1 分钟，约 300 MB 存在浏览器缓存里。
- 需要较新的 Chrome / Edge / Firefox / Safari，且不能是无痕模式。

## 本地运行

需要 Node.js ≥ 22、pnpm。`pnpm extract` 转码原版音乐需要 `ffmpeg`（没有则保留 WAV）。

```bash
pnpm install
pnpm gen            # 生成水墨版素材到 public/assets（约 2 分钟）
pnpm dev            # 打开 http://localhost:5173
# 可选：从你的原版生成 public/assets-orig，然后在游戏设定里切换
pnpm extract ~/Downloads/三国群英传3合集.exe
```

### 在手机 / 平板上玩

`pnpm dev` 会同时监听局域网地址（终端里显示的 `Network: http://192.168.x.x:5173`）。手机连同一个 Wi-Fi，用浏览器打开即可；横屏游玩，可“添加到主屏幕”以全屏运行。

### 打包发布（静态网站）

```bash
pnpm build          # 产物在 dist/（含 public/ 下的素材，可放到任何静态服务器 / NAS）
pnpm preview --host
```

生产构建带 Service Worker，素材首次加载后离线缓存。推送到 `main` 后，GitHub Actions 会生成水墨版素材、构建并部署到 GitHub Pages（不含原版素材）。
